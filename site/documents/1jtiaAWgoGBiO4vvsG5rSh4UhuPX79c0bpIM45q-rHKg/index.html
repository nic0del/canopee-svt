Thème 01 - Transmission, variation et expression du patrimoine génétique

✎ Vous pouvez répondre directement dans cette page. Vos réponses restent sur cet appareil et ne sont pas transmises à votre enseignant.

Contexte

Les séances précédentes ont montré que l’information génétique est portée par l’ADN, qu’elle peut être copiée lors de la réplication et modifiée par des mutations. Le TP sur le gène HBB a également montré qu’une variation de la séquence d’ADN peut être associée à une protéine différente. Il reste à comprendre comment l’information d’un gène est utilisée pour fabriquer une protéine.

Problématique

Comment l’information portée par l’ADN, situé dans le noyau, peut-elle être utilisée pour fabriquer une protéine dans le cytoplasme ?

Objectif

Mettre en évidence le rôle d’un ARN intermédiaire puis comprendre le mécanisme de transcription d’un gène.

Consigne

Travaillez individuellement. Répondez aux questions en utilisant les documents et un vocabulaire précis. Les séquences doivent être écrites en respectant le sens 5’ → 3’.

1. Une information à transporter du noyau vers le cytoplasme

Document 1 — Deux lieux différents dans la cellule

Dans une cellule eucaryote, l’ADN est localisé dans le noyau. Les protéines sont synthétisées par les ribosomes, situés dans le cytoplasme ou associés au réticulum endoplasmique. L’ADN ne quitte pas le noyau.

Des molécules d’ARN sont présentes dans le noyau et dans le cytoplasme. Elles sont beaucoup plus courtes que les chromosomes et peuvent franchir les pores nucléaires.

2. ADN et ARN : des molécules apparentées

Document 2 — Comparaison de l’ADN et de l’ARN

ADN : généralement deux brins ; sucre = désoxyribose ; bases azotées = A, T, C et G.

ARN : généralement un seul brin ; sucre = ribose ; bases azotées = A, U, C et G.

3. La transcription : synthétiser un ARN à partir de l’ADN

Document 3 — Un fragment de gène modèle

Brin non transcrit (brin codant) : 5’ – ATG GGC TTT CAG TGA – 3’

Brin transcrit (brin matrice) : 3’ – TAC CCG AAA GTC ACT – 5’

Lors de la transcription, l’ARN polymérase se déplace le long du brin transcrit et assemble des ribonucléotides complémentaires. Dans l’ARN, l’uracile U remplace la thymine T.

Règles de complémentarité : A de l’ADN → U dans l’ARN ; T → A ; C → G ; G → C.
