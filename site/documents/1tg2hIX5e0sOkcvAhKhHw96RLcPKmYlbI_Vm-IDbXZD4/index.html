Contexte

L’organisme pluricellulaire est formé de cellules de différentes formes et assurant des fonctions très différentes.

Problématique

Comment, à partir d’une cellule œuf unique, les cellules d’un organisme se différencient afin d’assurer une fonction particulière ?

Objectif

Déterminer comment les cellules se différencient alors qu’elles sont toutes issues d’une même cellule.

Consigne

Après avoir étudié les documents ci-dessous, vous proposerez une hypothèse permettant d’expliquer la spécialisation des cellules dans une organisme pluricellulaire.

Document 1

Document 1 : Evolution du nombre et du type de cellules depuis la cellule oeuf jusqu’au nouveau-né. Le caryotype des différents types de cellules est indiqué.

Document 2 : L’expression génétique.

Document 3

Document 3 : Deux gènes du chromosome 7.

Document 5

Document 5 : L’expression des gènes dans les cellules de quelques organes. Les techniques actuelles de la génétique permettent d’analyser rapidement l’expression de très nombreux gènes. En 2018 on disposait de données sur l’expression de 19 613 gènes sachant que le nombre total de gènes sur les chromosomes humains est compris entre 20 000 et 25 000. Certains gènes sont spécifiques à un organe, c’est-à-dire qu’ils sont exprimés uniquement dans les cellules de cet organe et pas ailleurs. D’autres gènes sont exprimés dans plusieurs organes.

Formuler une hypothèseÀ vous de répondre

Conservé sur cet appareil uniquement
Afficher un élément de réponse
Les cellules d’un organisme possèdent la même information génétique, mais elles n’expriment pas toutes les mêmes gènes. Cette expression différente est liée à leur spécialisation.
