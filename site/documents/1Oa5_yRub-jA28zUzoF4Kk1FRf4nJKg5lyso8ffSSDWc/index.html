L’équilibre d’Hardy Weinberg

Contexte

En 1908, le mathématicien britannique Geoffroy Hardy et le médecin allemand Wilhelm Weinberg proposent un modèle théorique qui prévoit que la fréquence des allèles et celle des génotypes d’une population sont constantes.

Problématique

Peut-on prévoir l’évolution d’une population allélique sur plusieurs générations grâce à ce modèle.

Objectif

On cherche à automatiser le calcul de Hardy Weinberg en utilisant un modèle informatique.

Consigne

Établir un script sous python permettant de prédire l’évolution allélique probable d’une population.

Partie 1 : Calculs de fréquences génotypiques

A l’usage des amateurs d’oiseaux, on a fabriqué aux USA une race de volailles de luxe et de prestige, les plumes frisées. Ce caractère de plumage est sous le contrôle d’un seul gène. Les volailles hétérozygotes pour ce gène sont de phénotype frisée. Les homozygotes pour ce gène sont soit de phénotype crépu soit de plumage normal.

Sur un échantillon de 1000 individus, on a dénombré 800 frisés, 150 normaux et 50 crépus.

En considérant que le gène responsable de l’aspect des plumes existe sous deux allèles différents,c pour crépu (récessif) et C pour un aspect normal (dominant).

En utilisant le script suivant sur le logiciel Edupython, vous calculerez les différentes fréquences génotypiques observées et théoriques (calculées selon le modèle de Hardy Weinberg).

Programme Python à utiliser :

A1 = str(input("entrer le nom de l'allèle dominant"))

A2 = str(input("entrer le nom de l'allèle récessif"))

M = float(input("Donner l'effectif du phénotype homozygote pour l'allèle dominant : "))

P = float(input("Donner l'effectif du phénotype hétérozygote : "))

S = float(input("Donner l'effectif du second phénotype homozygote pour l'allèle récessif : "))

T = M+S+P

B1 = ((2*M+P)/(2*T))*((2*M+P)/(2*T))

B2 = ((2*(2*M+P)/(2*T)))*((2*S+P)/(2*T))

B3 = ((2*S+P)/(2*T))*((2*S+P)/(2*T))

C1 = M/T

C2 = P/T

C3 = S/T

print ("La fréquence théorique du génotype ( ", A1,"//", A1," ) selon le modèle  de Hardy Weinberg est de " , B1," alors que celle observée dans la population est de ",C1)

print ("L'effectif théorique du génotype ( ", A1,"//", A2," ) selon le modèle de Hardy Weinberg est de " , B2," alors que celle observée dans la population est de ",C2)

print ("L'effectif théorique du génotype ( ", A2,"//" ,A2," ) selon le modèle de Hardy Weinberg est de " , B3," alors que celle observée dans la population est de ",C3)
