Fiche technique — Tracer une droite isochrone Rb/Sr au tableur

1. Ouvrir les données et vérifier leur format

Ouvrez le fichier élève : Ouvrir les données Rb-Sr dans le site

Ou recopiez les mesures dans trois colonnes : référence de l’échantillon, x = ⁸⁷Rb/⁸⁶Sr, y = ⁸⁷Sr/⁸⁶Sr.

Les valeurs de x doivent être numériques (par exemple 26,23), celles de y comprises autour de 0,76 à 0,90. Vérifiez le séparateur décimal correspondant à votre langue : virgule dans une configuration française, point dans certaines configurations anglaises. Si les nombres restent du texte, utilisez l’outil de conversion de texte en colonnes ou modifiez le paramètre de langue des cellules.

2. Construire le bon graphique : un nuage de points XY

Sélectionnez uniquement les colonnes x et y, SANS la colonne contenant les codes d’échantillons.

Dans LibreOffice Calc : Insertion → Diagramme → XY (dispersion), puis « Points uniquement ».

Dans Excel : Insertion → Nuage de points (XY) → marqueurs seuls.

Dans Google Sheets : Insertion → Graphique → Type « Nuage de points ».

Vérifiez : abscisse = ⁸⁷Rb/⁸⁶Sr ; ordonnée = ⁸⁷Sr/⁸⁶Sr.

Ajoutez un titre, des titres d’axes et si possible un quadrillage. Les rapports isotopiques sont sans unité.

3. Ajouter la droite isochrone

Calc : sélectionner la série de points → Insérer une courbe de tendance → Linéaire ; afficher l’équation et, si proposé, R².

Excel : clic droit sur les points → Ajouter une courbe de tendance → Linéaire → « Afficher l’équation sur le graphique » et « Afficher le coefficient de détermination (R²) ».

Google Sheets : Personnaliser → Série → Courbe de tendance → Linéaire ; étiquette : « Utiliser l’équation » ; afficher R².

Vous devez trouver une pente positive voisine de 0,00437. Si l’équation arrondit la pente à 0,004 ou 0,00, affichez davantage de décimales ou utilisez les fonctions de régression du tableur.

4. Retrouver la pente avec une fonction

Dans le fichier élève fourni, les x sont en B6:B14 et les y en C6:C14 :

— LibreOffice / Excel configuré en français : =PENTE(C6:C14;B6:B14)

— Excel / Google Sheets configuré en anglais : =SLOPE(C6:C14,B6:B14)

Les langues et séparateurs des fonctions dépendent du logiciel et des paramètres régionaux. Vous pouvez aussi lire la pente dans l’équation de tendance en augmentant la précision.

Pour l’ordonnée à l’origine : ordonnée à l’origine du graphique ou fonction d’interception selon le logiciel.

5. Calculer l’âge

On pose a = pente de la droite, λ = 1,42 × 10⁻¹¹ an⁻¹.

Écrivez dans une cellule : =LN(1+a)/1.42E-11 si votre tableur accepte le point décimal et que a est remplacé par une référence de cellule. En configuration française, entrez plutôt la constante numérique comme 1,42E-11 et référez-vous à la cellule qui contient a.

Exemple : si la pente est en E4 et λ en E5, dans E6 utilisez =LN(1+E4)/E5 puis dans E7 =E6/1000000.

ATTENTION : ne tapez pas « a » comme une lettre si aucune cellule ou plage ne porte ce nom.

L’âge est exprimé en années avant d’être converti en millions d’années (Ma).

6. Vérifier et enregistrer la production

Votre fichier doit montrer : les données ; le nuage XY ; la droite linéaire ; une équation assez précise ; les calculs ; une conclusion scientifique.

Si vous avez fini, contrôlez si l’âge obtenu est cohérent avec une valeur de l’ordre de 300 Ma et expliquez la condition de fermeture du système.

En cas de panne

Si le logiciel ne fonctionne pas, utilisez l’équation de référence fournie par l’enseignant : y ≈ 0,00436595 x + 0,71171349 et réalisez les calculs sur votre feuille. Cette aide technique ne remplace pas l’explication scientifique de la méthode.
