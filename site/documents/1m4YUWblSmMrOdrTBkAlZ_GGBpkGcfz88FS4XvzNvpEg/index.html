Méthode : réussir une étude de documents

Contexte

L’évaluation de lundi demandera de mobiliser les connaissances des chapitres 1, 2, 3 et 6 et de les utiliser pour interpréter des documents scientifiques.

Problématique

Comment construire une réponse scientifique à partir d’informations tirées d’un ou plusieurs documents ?

Objectif

Apprendre à extraire une information, la quantifier ou la comparer, l’interpréter avec les connaissances du cours puis conclure clairement.

Consigne

Pour chaque exercice, distinguez ce que vous observez dans le document de ce que vous connaissez déjà. Une bonne réponse doit relier les deux.

La méthode en 4 étapes

1. Je relève une information précise dans le document.

Je cite une valeur, une évolution, une différence ou un élément observable. J’évite les phrases vagues du type « ça augmente beaucoup ».

2. Je compare ou je quantifie si c’est possible.

Je donne des valeurs, un écart, un rapport ou une évolution.

3. J’interprète avec une connaissance du cours.

J’explique le résultat en utilisant le vocabulaire scientifique adapté.

4. Je conclus en répondant explicitement à la question.

La conclusion doit être courte et directement reliée au problème posé.

Exercice 1. Un document quantitatif : UV et mutations

Document 1. Données simplifiées obtenues sur une culture de levures.

Les UV sont un rayonnement capable d’endommager l’ADN.

Question : Montrez à partir du document que les UV augmentent la fréquence d’apparition des mutations, puis expliquez ce résultat à l’aide de vos connaissances.

Exercice 2. Mettre deux documents en relation

Document 2a. Localisation d’un ARN nouvellement synthétisé.

Des cellules eucaryotes reçoivent pendant quelques minutes un précurseur marqué qui est incorporé uniquement dans les ARN nouvellement synthétisés.

Après 5 min : 82 % du marquage est dans le noyau et 18 % dans le cytoplasme.

Après 30 min : 34 % du marquage est dans le noyau et 66 % dans le cytoplasme.

Document 2b. Effet d’un inhibiteur de l’ARN polymérase.

En présence d’un inhibiteur de l’ARN polymérase, l’incorporation du précurseur marqué dans les ARN tombe à 7 % de la valeur mesurée dans les cellules témoins.

Question : À l’aide des deux documents et de vos connaissances, montrez que les ARN sont synthétisés dans le noyau par l’ARN polymérase puis qu’une partie d’entre eux gagne le cytoplasme.

À éviter lundi

• Paraphraser le document sans l’interpréter.

• Réciter le cours sans utiliser les données du document.

• Dire « on voit que » sans citer de valeur ou d’élément précis.

• Donner une conclusion qui ne répond pas directement à la question.
